INTRODUCTION TO COMPUTING

Understanding Computers and Information

Lesson 1: Information Systems

An information system is a combination of people, procedures, data, and technology used to collect, process, store, and share information.

Components of an Information System

  1. Hardware: Physical computer equipment.
    2. Computer Hardware

    Computer Hardware Components

  2. Software: Programs used to perform tasks.
  3. Data: Facts that can be processed into information.
  4. People: Users who operate the system.
  5. Procedures: Rules and instructions for using the system.
  6. Networks: Connections that allow devices to exchange information.

Examples of Information Systems

  • School enrollment systems
  • Hospital information systems
  • Banking systems
  • Inventory systems
  • Online shopping systems

Example: A school information system stores student names, grades, attendance, and enrollment records.


Lesson 2: Database and MySQL

A database is an organized collection of related data. A database management system helps users create, organize, retrieve, and update that data.

MySQL is a relational database management system that uses SQL to work with data stored in tables.

Lesson 3: Entities, Attributes and Relationships

An entity is a person, place, object, event, or concept about which data is stored.

Two Common Entity Categories

  • Strong Entity: Has its own key to identify its records.
  • Weak Entity: Depends on another entity for identification.

Examples of Entities

  • Student
  • Teacher
  • School
  • Book
  • Product
  • Transaction

Types of Attributes

  • Simple: Cannot be divided into smaller meaningful parts.
  • Composite: Can be divided into smaller parts.
  • Single-valued: Has one value per entity.
  • Multivalued: Can have several values.
  • Derived: Calculated from other information.
  • Key Attribute: Helps uniquely identify a record.

Degree of a Relationship Set

Degree Description
UnaryInvolves one entity type.
BinaryInvolves two entity types.
TernaryInvolves three entity types.
N-aryInvolves more than three entity types.

Example: A student enrolls in a subject. Student and Subject form a binary relationship.

Lesson 4: Computer Memory and Storage

Computer memory holds data and instructions needed for processing. Storage devices keep files and information for future use.

Types of Primary Memory

  • RAM: Temporary working memory. Its contents are generally lost when power is turned off.
  • ROM: Memory that retains important instructions without power.

Types of Secondary Memory

  • HDD: Uses rotating magnetic disks.
  • SSD: Uses flash memory without moving mechanical parts.
  • USB Flash Drive: Portable data storage.
  • Memory Card: Used in many portable devices.
  • Optical Disc: Includes CD, DVD, and Blu-ray.
  • Magnetic Tape: Often used for backups and archives.

Magnetic Tape

Magnetic tape stores data magnetically on a long strip of tape. It is useful for long-term backup and storing large amounts of information.

Storage Measurements

Unit Meaning
BitA binary digit: 0 or 1.
Byte8 bits.
KBApproximately 1,000 bytes.
MBApproximately 1 million bytes.
GBApproximately 1 billion bytes.
TBApproximately 1 trillion bytes.
PBApproximately 1 quadrillion bytes.

Binary units differ: 1 KiB = 1,024 bytes.

Basic Hardware Components

  • Input Devices: Enter data.
  • CPU: Executes instructions.
  • Memory: Holds working data.
  • Storage: Keeps files and programs.
  • Output Devices: Present results.
  • Motherboard: Connects components.

Parts of the System Unit

  1. Motherboard
  2. Central Processing Unit (CPU)
  3. Random Access Memory (RAM)
  4. Storage drive
  5. Power Supply Unit (PSU)
  6. Cooling fans or heat sink
  7. Expansion cards
  8. Computer case

Types of Monitors

  • CRT: Older, bulky display technology.
  • LCD: Uses liquid crystals.
  • LED: Commonly an LCD monitor with LED backlighting.
  • OLED: Uses self-emitting pixels.
  • Touchscreen: Supports interaction by touch.

Output Devices

  • Monitor
  • Printer
  • Speakers
  • Headphones
  • Projector
  • Plotter

Connecting Computers and Applying Digital Skills

Lesson 1: Data Communication

Data communication is the exchange of data between devices through a transmission medium.

Basic Components of Data Communication

  1. Sender: Sends the data.
  2. Receiver: Receives the data.
  3. Message: The information being sent.
  4. Transmission Medium: The path through which data travels.
  5. Protocol: Rules that control communication.

Popular Forms of Data

  • Text: Letters, words, and characters.
  • Numbers: Numeric values.
  • Images: Photos, drawings, and graphics.
  • Audio: Speech, music, and sound.
  • Video: Moving visual images, often with sound.

Types of Networks

Network Meaning

LANLocal Area Network.
WLANWireless Local Area Network.
MANMetropolitan Area Network.
WANWide Area Network.

Internet and World Wide Web

The Internet is a worldwide network connecting computer networks. It allows users to communicate and share information.

The World Wide Web (WWW) is a collection of linked web pages and resources accessed through the Internet using a web browser.

Examples of Internet Services

  • Email
  • Social networking
  • Online learning
  • Video conferencing
  • Cloud storage
  • Web browsing

HISTORY OF COMPUTING

What is the History of Computing?

The history of computing explains how computers developed from simple counting tools into modern electronic machines. Early people used tools to calculate numbers and solve mathematical problems. As time passed, inventors created mechanical calculators, programmable machines, and electronic computers. Today, computers are faster, smaller, and more powerful. They are used in education, communication, business, medicine, science, and many other fields.

Development of Computing

Period Development
Early Times People used counting tools such as the abacus to perform calculations.
Mechanical Era Inventors developed mechanical calculators and machines that could perform calculations.
Electronic Era Electronic computers were created to process information faster than earlier machines.
Modern Era Computers became smaller and more powerful. Personal computers, laptops, smartphones, and cloud services became common.

Why is Computing Important?

  • It helps people solve problems.
  • It makes communication faster.
  • It helps store and organize information.
  • It supports education, business, and research.
  • It makes many everyday tasks easier.

FORMS OF COMPUTING

What are Forms of Computing?

Forms of computing refer to the different ways computers and computing resources are used to process information and perform tasks. Each form of computing has its own purpose. Some are designed for personal use, while others support large organizations, scientific research, or online services. These forms help people complete tasks efficiently and solve different kinds of problems.

Different Forms of Computing

1. Personal Computing

Personal computing refers to using a computer for individual tasks. People use personal computers and laptops for studying, writing documents, browsing the Internet, playing games, and creating presentations.

2. Mobile Computing

Mobile computing allows people to use portable devices such as smartphones and tablets while moving from one place to another. It provides access to information, communication, and applications through wireless connections.

3. Cloud Computing

Cloud computing provides computing services through the Internet. Users can store files, access applications, and use online resources without keeping everything on their own devices. Examples include online storage and web-based applications.

4. Parallel Computing

Parallel computing uses multiple processors or processing units to work on different parts of a problem at the same time. It can help complete complex tasks faster, such as scientific calculations, simulations, and data processing.

Lesson 4
TYPES OF COMPUTING ENVIRONMENT

What is a Computing Environment?

A computing environment is the setting where computers, software, networks, and other resources are used to process information. Different computing environments are designed for different purposes, such as personal use, business operations, communication, and sharing resources.

Common Computing Environments

1. Personal Computing Environment

This environment is used by one person for activities such as studying, writing documents, browsing the Internet, and playing games. Examples include desktop computers and laptops.

2. Client-Server Environment

In this environment, client computers request services or information from a central server. For example, a school computer may access student records stored on a school server.

3. Distributed Computing Environment

Distributed computing uses multiple computers connected through a network. These computers work together to complete tasks and share information.

4. Cloud Computing Environment

Cloud computing allows users to access storage, applications, and computing services through the Internet. Examples include online file storage and web-based applications.

5. Mobile Computing Environment

Mobile computing allows people to use portable devices such as smartphones and tablets while moving from one location to another.

6. Virtual Computing Environment

Virtual computing uses software to create virtual computers or systems inside a physical computer. It allows different operating systems or computing environments to run on one machine.
